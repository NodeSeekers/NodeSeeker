# NodeSeek Helper

NodeSeek 非官方 Chrome MV3 扩展，提供用户标签、用户趋势、自动传图、阅读导航、快捷评论、快捷短语、抽奖通知、访问足迹和同步备份等实用功能。

## 功能

- 标签数据：在帖子楼层作者信息后展示用户标签，支持选择字段、拖动排序、设置标签尺寸和不同等级标签颜色/透明度。
- 用户趋势：鼠标悬停用户头像时展示近 7 天和近 30 天的鸡腿、主题、评论、星辰趋势图。
- 内容管理：按关键词或用户名屏蔽内容，并通过多组标记关键词、标记用户规则设置组名和样式。
- 图床配置：在 NodeSeek 编辑器里粘贴图片时，上传到 Nodeimage 并插入 Markdown 图片链接。
- 阅读导航：支持签到提醒、从列表进入详情页后快捷换帖，也支持到达帖子详情页或首页列表顶部/底部后继续滚动切换上一页或下一页。
- 快捷评论：在帖子页面右侧快捷功能区增加快捷评论按钮。
- 快捷短语：在帖子编辑器工具栏插入已保存短语，支持多行短语、新增、编辑、删除、快捷键唤起面板，以及选中编辑器文字后快速保存为短语。
- 抽奖通知：在帖子中检测到开奖链接时，可添加到本机抽奖通知列表，并在选项页查看。
- 访问足迹：进入帖子详情页后会保存在本机历史中，帖子列表中的已读标题会显示为灰色，并可按标题、发帖人和发帖时间筛选。
- 同步备份：支持导出和导入扩展配置 JSON，便于迁移页面标签、内容管理规则、阅读导航、快捷短语等设置。
- Telegram 通知：支持个人聊天和频道 Direct 目标；监控新私信并转发发送者、正文和链接，也可通过 NodeSeek RSS 按关键词、组合词、屏蔽词和版块推送新帖。Bot Token、目标和规则只保存在本机。
- 本地缓存：用户资料、趋势历史、抽奖通知、访问足迹和今日签到记录会保存在本机，默认 24 小时后重新拉取用户资料。

## 使用

1. 打开 `chrome://extensions`。
2. 开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 打开扩展详情页里的“扩展程序选项”，按需配置页面标签、内容管理、Nodeimage API Key、阅读导航、快捷短语、抽奖通知、访问足迹和同步备份。
5. Telegram 通知在阅读导航设置中配置；个人聊天需先启动 Bot，频道 Direct 需配置 Chat ID 和主题 ID。

## 开发与验证

- `npm test`：运行 Playwright 扩展启动、设置持久化和后台消息测试。
- `npm run package`：生成 `dist/nodeseek-seeker-v<manifest.version>.zip`，只包含扩展运行所需文件和安全的示例初始化配置。
- `npm run debug:cdp`：启动带扩展的 Playwright Chromium，使用 `.debug/chromium-profile` 持久配置。
- `npm run test:cdp`：只读检查真实 NodeSeek 页面导航；不会发布帖子、回复或评论。

## 项目结构

- `manifest.json`：Chrome MV3 扩展清单和脚本加载入口。
- `src/background/`：后台消息路由、IndexedDB、图片上传、抽奖通知、访问足迹和数据保留逻辑。
- `src/content/`：页面内容脚本，按上传、阅读导航、抽奖快捷操作、快捷短语、用户资料和启动逻辑拆分。
- `src/main-world/`：运行在页面主世界的编辑器桥接脚本。
- `options/`：扩展选项页，按共享状态、设置表单、抽奖列表和本地数据操作拆分。
- `assets/`：扩展图标资源。

## 数据说明

- Nodeimage API Key 仅保存在本机扩展存储中。
- Telegram Bot Token、Chat ID、Direct 主题 ID、私信正文和 RSS 规则只保存在本机扩展存储中；私信正文会按目标配置发送到 Telegram。
- 本地配置文件 `nodeseek-config.json` 不纳入 Git，也不会进入扩展 ZIP。
- `examples/nsh-preloaded-config.json` 是全新安装时使用的示例初始化配置；可包含演示规则，但必须保持 API Key、Bot Token 和 Telegram 推送目标为空。
- 扩展设置、快捷短语、用户资料缓存、趋势历史、Readme、抽奖通知、访问足迹和今日签到记录仅保存在本机，用于功能配置、展示标签、趋势图、用户详情、已读状态和签到状态。
- Readme 正文按 SHA-256 hash 去重存储，历史快照只保存引用。
- 清空数据会删除本机保存的用户资料、趋势历史、Readme 引用、抽奖通知、访问足迹和今日签到记录。
